# Archive of www.guardianangels.foundation (Weebly site)

Captured 2026-07-12 as the content source for the rebuild.

- `html/` — raw HTML of all 14 live pages (+ root index)
- `images/` — all 102 uploaded images referenced by those pages (38 MB)
- `text/` — plain-text extraction per page for content review
- `image-urls.txt` — original upload URLs

Two additional pages were added to the live Weebly site after the initial capture and
were pulled in on 2026-09-06: `chicago-midwest-chapter.html` and `india.html`
(plus their 8 new images). Rebuilt as `chicago-midwest-chapter.html` and `india.html`
at the repo root.

Donations run through external subdomains (give./gift.guardianangels.foundation);
those links must carry over to the new site.
